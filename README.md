# Morni-Singhs

> **Boutique Mountain Sanctuary at 1,220m Elevation · Bhoj Darara, Morni Hills, Haryana**

An ultra-luxury, image-bright web application crafted for **Morni Singh's**, an exclusive 2BHK mountain residence perched in the pristine pine-scented Shivalik foothills.

---

## 🌟 Key Features

- **2-Second Theatrical Ascent Page Loader**:
  - Live elevation ascent meter counting from `0m` to `1,220m`.
  - Official animated Morni Singh's logo emblem with rotating celestial orbital ring and radiant halo.
  - Hairline gold shimmer progress bar with smooth blur exit.
- **100% Transparent Floating Header**:
  - Pure transparent view over high-resolution hero imagery at the top of the page.
  - Auto-floats into dark crystal glass (`backdrop-blur-xl`) with smooth ticker auto-collapse on scroll.
  - Guaranteed single-line navigation (`whitespace-nowrap`) and balanced luxury CTA pills (WhatsApp & Reserve Stay).
- **Sensory Timeline (24 Hours at Morni Singh's)**:
  - Continuous smooth auto-scrolling with play/pause toggle.
  - Manual Next/Prev circular arrows, direct chapter jump pills (01 to 07), mouse drag, mouse wheel, and touch swipe.
- **Mobile-Optimized Experience**:
  - Reduced vertical scrolling by ~4,000px using horizontal touch-swipe chapter carousels.
  - Professional sticky booking dock with dedicated phone bubble and reservation bubble (zero clutter).
- **Extreme Performance & WebP Optimization**:
  - 90% bandwidth reduction (converted 57MB of raw PNG assets down to ~6MB modern WebP).
  - Fast page loading times with zero layout shift.
- **Rich Photographic Gallery & Room Switcher**:
  - Full-screen lightbox archive with curated editorial filters.
  - Interactive 360-feel room switcher with authentic photography.

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Luxury Glassmorphism & Gold Tokens
- **Animations**: Framer Motion + Lucide React Icons
- **Routing**: React Router DOM v7
- **Linter**: Oxlint (0 errors, 0 warnings)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/gexart/Morni-Singhs.git

# Navigate into project directory
cd Morni-Singhs

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Type check and build optimized bundle
npm run build

# Preview production build locally
npm run preview
```
